# TBO v1.0.0 Release Notes

Commit range: `fd4a38b` (initial commit) to `d03d116` (Version 1.0.0 Release).

## Highlights

- Initial public release of the `Titanis.TBO.Smb2` PowerShell module.
- Added the `TBO.Smb2` PowerShell provider for SMB access using backup intent for backup-operator style workflows.
- Added the `TBO.Reg` PowerShell provider (preview) and registry cmdlets for remote registry enumeration and modification.
- Added cmdlets for common credential and secret collection paths (LSA secrets, SAM hashes, CachedLogons, machine account, scheduled tasks, CredMan, DPAPI master keys and blobs).
- Included build and packaging automation plus usage documentation.

## Providers

- `TBO.Smb2`: SMB provider exposing UNC paths and shares as a PSDrive with on-demand connections and support for standard PowerShell file operations.
- `TBO.Reg` (preview): remote registry provider exposing hives and keys as a PSDrive with optional value enumeration and typed value reads.

## Cmdlets

- SMB and file operations: `Connect-TBOSmbServer`, `Disconnect-TBOSmbServer`, `Set-TBOConnectOptions`, `Set-TBOSmbConnectOptions`, `Copy-TBOSmbItem`, `Out-TBOSmbFile`, `Watch-TBOSmb`.
- SMB enumeration: `Get-TBOSmbNics`, `Get-TBOSmbShares`, `Get-TBOSmbSessions`, `Get-TBOSmbOpenFiles`, `Get-TBOSmbSnapshots`, `Get-TBOSmbStreams`.
- SMB security descriptors: `Get-TBOSmbSecurityDescriptor`, `Set-TBOSmbSecurityDescriptor`.
- Registry provider/session management: `Set-TBORegConnectOptions`, `Get-TBORegSessions`.
- Registry key and value operations: `Get-TBORegKey`, `New-TBORegKey`, `Remove-TBORegKey`, `Get-TBORegValue`, `Set-TBORegValue`, `Remove-TBORegValue`, `Get-TBORegChildItem`.
- Registry security descriptors: `Get-TBORegSecurityDescriptor`, `Set-TBORegSecurityDescriptor`.
- Registry secrets and host data: `Get-TBORegSecretLocations`, `Get-TBORegAutoLogon`, `Get-TBORegCachedCredentials`, `Get-TBORegLsaKeys`, `Get-TBORegLsaSecrets`, `Get-TBORegMachineAccount`, `Get-TBORegSamHashes`, `Get-TBORegServices`, `Get-TBORegServiceDetails`, `Get-TBORegTCPIP`, `Find-TBORegWeakServices`.
- DPAPI and CredMan: `Get-TBODpapiMasterKeyLocations`, `Get-TBODpapiMasterKeys`, `Get-TBODpapiBlob`, `Find-TBODpapiBlobs`, `Get-TBOCredManFiles`, `Get-TBOCredManEntry`.
- Scheduled tasks: `Get-TBOScheduledTasks`, `Get-TBOScheduledTaskDetails`.
- Hash helpers: `Get-TBONtHash`.

## Documentation and Build

- Added `Docs/Usage.md` with examples for providers and cmdlets.
- Added provider about-help: `en-US/about_TBO_Smb2_Provider.help.txt` and `en-US/about_TBO_Reg_Provider.help.txt`.
- Added build scripts: `Build/Build-Module.ps1` and `Build/Update-Version.ps1`.
