# TBO v3.5.0 Release Notes

This release captures changes on `dev` from `fdae623db6f3419d0c1928ac6f78521643a053f2` to `76a02026afd1a6d22c08b5e12f23a11f1e9204e8`.

## Highlights

- Added Windows Hello private-key decryption support in `Get-TBONGCCryptoKeys` with PIN-based unlock paths.
- Expanded local-registry parity with additional localhost aliases, SACL support, and SID resolution options for session output.
- Added reboot-persistent service-registry scenario helpers and improved reparse-point handling in SMB copy workflows.

## New Cmdlets

- None.

## Improvements

- NGC: `Get-TBONGCCryptoKeys` now supports PIN-assisted private-key decryption flows (`TBO-c4s`).
- Registry sessions: `Get-TBORegSessions` added `-ResolveSid` support without requiring LSA secret material (`TBO-01p`).
- Local registry: Added alias support for `.`, machine-name, and loopback targets (including IPv4/IPv6 loopback) (`TBO-twi.10`).
- Local registry: Added local SACL retrieval/write support using `SeSecurityPrivilege` handling (`TBO-twi.9`).
- Service details: `Get-TBORegServiceDetails` now includes additional `Parameters` and `Performance` technique data.
- SMB copy: Added optional reparse traversal behavior (`-FollowReparse`) with safeguards for projected/unknown filesystem cases (`TBO-mg0`).
- Service scenarios: Added reboot-persistent service-registry create scenarios (`TBO-8vx`).

## Bug Fixes

- Improved copy reliability for directory trees containing reparse points by adding explicit, opt-in traversal semantics with guardrails.

## Documentation

- Updated `Docs/Usage.md` with NGC PIN, local-registry alias/SACL, and reparse-copy guidance.

## Known Issues

- None currently known specific to this release.
