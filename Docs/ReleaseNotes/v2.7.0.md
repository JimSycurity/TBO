# TBO v2.7.0 Release Notes

This release captures changes on `dev` from `c5bd70b4195ca4e89a84e50445a9b717dab22681` to `645ca28fdb27cbb3f918673031b13d47c676742f`.

## Highlights

- Added local NTFS support paths for the PowerShell provider and file cmdlets, including create/delete, content IO, and security descriptor operations.
- Expanded Chromium coverage with profile enumeration and browser-family support, plus state-key extraction output.
- Added scheduled task TaskCache security descriptor round-trip support.

## New Cmdlets

- `Get-TBOChromiumStateKeys`
- `Set-TBOScheduledTaskSecurityDescriptor`

## Improvements

- SMB/local provider: Added local-mode provider navigation and PSDrive behavior for backup-intent workflows.
- Local mode: Added `@GMT` snapshot token handling and local snapshot/metadata support plumbing.
- Chromium: Added broader browser targeting and improved profile selection behavior.
- Scheduled tasks: Improved task security descriptor read/write handling for TaskCache-backed operations.

## Bug Fixes

- None called out separately in this release range.

## Documentation

- Added `Docs/DevGuide/PowerShellSmb2LocalNtfs.md`.
- Updated `Docs/Usage.md` with local-mode and Chromium usage updates.
