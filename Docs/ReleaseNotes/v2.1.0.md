# TBO v2.1.0 Release Notes

This release captures changes on `dev` since `v2.0.0` was released on `main` (`0fc0841`).

## Highlights

- Registry: `Set-TBORegSecurityDescriptor` reliability improvements when writing remote registry security descriptors (including better defaults and retry behavior).
- Chrome: Hardened Chrome SQLite snapshot parsing with retry/backoff and additional verbose diagnostics for transient failures (no output schema changes).
- Documentation: Added `v1.0.0` release notes.

## New Cmdlets

- None.

## Improvements

- Registry: `Set-TBORegSecurityDescriptor` now defaults `-Sections` to `Dacl` (safer default) and docs/examples show explicit `-Sections` usage.
- Registry: Improved access mask selection when opening keys for security descriptor writes by including a safe baseline of registry rights (such as `KEY_QUERY_VALUE`) alongside standard rights.
- Registry: Improved root hive open behavior to avoid requesting unsupported/invalid rights on root handles when targeting subkeys.
- Registry: On access denied, retries once with `BACKUP_SECURITY_INFORMATION`, then (if still denied) retries with a `KEY_ALL_ACCESS` handle (with verbose diagnostics).
- Chrome: Chrome SQLite snapshot open/query now retries up to 3 attempts with short bounded backoff on transient failures.
- Chrome: Added verbose diagnostics describing snapshot DB/WAL/SHM presence and local file sizes for each attempt.

## Bug Fixes

- `Set-TBORegSecurityDescriptor`: Fixed failures encountered on some servers when setting DACLs (tracked as `TBO-rh4` in `v2.0.0` known issues).

## Documentation

- Added `Docs/ReleaseNotes/v1.0.0.md`.
- Updated `Docs/Usage.md` and cmdlet help examples for `Set-TBORegSecurityDescriptor`.

## Known Issues

- None currently known specific to this release.
