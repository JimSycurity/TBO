# TBO v3.1.0 Release Notes

This release captures changes on `dev` from `57be7daff7c99ab9835c456f8fb127a0893396d9` to `fdae623db6f3419d0c1928ac6f78521643a053f2`.

## Highlights

- Introduced the SQLite-backed TBO cache subsystem (storage, ingestion, graph export, and management cmdlets).
- Added broader DPAPI/NGC/AAD coverage including memory-dump scanning, CREDHIST decryption, Windows Hello parsing, and AAD Connect credential extraction.
- Added remote environment-variable cmdlets and SOCKS5 proxy support for SMB transport workflows.

## Improvements

- Cache: Added schema-backed entity model for machines, principals, credentials, and observations with ingestion helpers across multiple cmdlets.
- Cache: Added graph export formats (`JSON`, `DOT`, and OpenGraph) and cache export surface for offline analysis pipelines.
- Cache: Added global ingestion toggle support (`TITANIS_TBO_CACHE_INGEST`) and machine-scoped principal identity handling.
- Registry/SAM: Improved local SAM principal SID derivation to stabilize cache identity mapping.
- Transport: Added SOCKS5 proxy plumbing for SMB operations.
- Build/runtime: Improved module loading behavior for SQLite dependencies, including `dotnet build -o` output scenarios.

## Bug Fixes

- Fixed cache/runtime dependency loading failures where `Microsoft.Data.Sqlite` side-by-side dependencies were missing or not selected correctly for module import (`TBO-8yd`).

## Documentation

- Added `Docs/DevGuide/TboCache.md`.
- Updated `Docs/Guide.md`, `Docs/README.md`, `Docs/Usage.md`, and `README.md` for cache, DPAPI, NGC, and environment-variable workflows.

## Known Issues

- None currently known specific to this release.
