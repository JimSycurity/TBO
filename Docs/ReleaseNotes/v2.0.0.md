# TBO v2.0.0 Release Notes

This release captures the cumulative changes on `dev` since `v1.0.0` was released on `main`.

## Highlights

- Expanded DPAPI triage and decryption coverage (CredMan, Vault, Chrome, Safari, machine certs).
- Improved DPAPI user master key support (user key derivation and CredHist handling for rotated keys).
- Improved CredMan and Scheduled Task credential parsing to produce more useful cleartext output when possible.
- Added registry secret caching and broader secret decoding helpers to reduce duplicated parsing logic and improve diagnostics.
- Multiple refactors to establish more consistent logging and error handling patterns across cmdlets and providers.

## New Cmdlets

- `Get-TBODpapiMasterKeyHashes`: Format machine and user master keys into hash material suitable for offline cracking workflows.
- `Get-TBOChromeLogins`: Parse and decrypt Chrome "Login Data" entries (DPAPI protected). Uses a local SQLite snapshot copy (including sidecar files) to handle locked databases.
- `Get-TBOChromeCookies`: Parse and decrypt Chrome cookies (prefers `Network\Cookies`, falls back to legacy `Cookies`). Uses a local SQLite snapshot copy (including sidecar files) to handle locked databases.
- `Get-TBOSafariKeychain`: Parse and decrypt Safari `keychain.plist` entries (DPAPI protected, with the known Safari entropy).
- `Get-TBOMachineCertificates`: Enumerate and decrypt machine certificate material protected by DPAPI.

## Improvements

- DPAPI: Added helpers for user key derivation and CredHist handling; improved cleartext decoding consistency and diagnostics across DPAPI consumers.
- CredMan: Improved DPAPI cleartext decoding and fallback heuristics for odd payloads; added helper infrastructure so output is more consistently decoded and easier to troubleshoot.
- Credential Vault: Improved decryption and parsing of Vault credential items (where a DPAPI blob is present).
- Scheduled Tasks: Improved extraction of embedded CredMan credential cleartext used by scheduled tasks.
- Registry / Secrets: Added a registry secret cache to reduce repeated reads and improve performance for multi-stage workflows; refactored secret decoding so common decoding paths and diagnostics are shared.
- Services: Improved weak service filtering behavior and parsing to avoid returning uninteresting access masks; service-related registry cmdlets refactored for better reuse and consistency.
- SMB provider / connection behaviors: Internal refactors to connection option handling and SMB provider implementation.

## Bug Fixes

- `Find-TBORegWeakServices`: Fixed default interesting access mask filtering to avoid including purely read/query rights.
- `Get-TBORegTCPIP`: Improved robustness in the presence of transient pipe busy conditions.

## Internal Refactors (Notable)

- New helper types introduced to centralize common logic: `RegistryHelpers`, `SecretDecodingHelpers`, `DpapiHelpers` (and DPAPI-focused helpers for user key derivation, CredHist handling, and master key formatting), plus cmdlet base classes for scheduled tasks and service-registry patterns.
- Updated formatting view (`Format.ps1xml`) to better present credential-related output.

## Documentation

- Updated `Docs/Usage.md` with new cmdlets and logging guidance.
- Updated `Docs/Build.md` and developer guidance docs.
